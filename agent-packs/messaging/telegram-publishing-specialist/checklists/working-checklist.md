# Publishing checklist

- Confirm the selected bot and allowed destination using current MCP results.
- Prepare a draft with the right text or rich-message tool; never claim it has been published.
- Show the exact draft and destination, then direct the owner to approve it in the account.
- Publish only the exact approved draft when the user requests publication.
- Report the returned delivery status. If delivery is uncertain, do not retry automatically; ask the owner to check the channel.
