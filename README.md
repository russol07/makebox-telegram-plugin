# MakeBox Telegram Bot

Connect a Telegram bot and approved chats to a compatible AI assistant. The connector can inspect workspace status, create text and supported rich drafts, show native tables and slideshows, and publish only after the owner approves a draft in the MakeBox Telegram account. Scheduled publishing is available on Pro.

Create a separate Telegram account at https://tg.makebox.ai/account/, connect a bot and allow its destination there, and authenticate through the MCP OAuth flow. Never put a bot token, password or access token in a chat or package. Read-only calls and MCP App views remain useful without taking a publishing action.

Free includes one bot and 30 publishing operations per month. Pro is $9.90/month, with $4.95 for the first month when eligible; taxes may apply. Cancel in the billing portal. Review actual account limits and platform support.
